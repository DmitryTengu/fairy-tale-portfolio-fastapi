# Сказочное портфолио иллюстратора

Сайт-портфолио художницы-иллюстратора детских книг и журналов, сделанный на FastAPI.
Особенность: прямо поверх страницы можно рисовать акварельными мазками, и рисунки всех
посетителей видны друг другу в реальном времени (WebSocket).

## Возможности
- Портфолио работ и интерактивные «книги» со слайдерами разворотов.
- Просмотр картинок в полноэкранном окне (закрывается по клику и клавише Esc).
- **Общий холст на WebSocket:** мазки сохраняются в SQLite, рассылаются всем посетителям и стираются через 30 минут. Панель кисти: две кисти (**акварель**: прозрачная заливка с мягкими краями, и **масло**: плотная краска с бороздами от щетины, светлым и тёмным краем), 8 цветов, 3 толщины, включение и выключение рисования (на телефоне по умолчанию выключено, чтобы не мешать скроллу), кнопка «скрыть чужие рисунки». **Ластик** работает как в Paint: подтирает только ваши собственные линии там, где вы проводите (размер ластика зависит от выбранной толщины), у всех посетителей тоже. Кнопка «Стереть все мои рисунки» чистит холст от ваших линий. Чужие рисунки стереть нельзя, сервер проверяет владельца. Холст перерисовывается из памяти и только видимая часть, поэтому сайт не тормозит при скролле.
- **Мини-игра «Найди героев»:** на странице прячутся герои сказок, по клику они улетают в «Книгу героев». Прогресс сохраняется в браузере, когда собраны все, предлагается написать художнице. Героев можно добавлять без правки кода, см. раздел «Герои игры».
- Картинки подбираются без учёта регистра (`portfolio1.JPG` и `portfolio1.jpg` на Linux-хостинге разные файлы), а если картинки нет, показывается мягкая заглушка.
- Защита сервера: мазки проверяются на сервере (числа, цвет, размер сообщения), ограничена частота сообщений от одного подключения.
- Под заголовками и текстом лежит мягкая «бумажная» подложка: чужие рисунки под текстом приглушаются, и читать текст можно всегда.
- Волшебная пыльца за курсором: звёзды, блёстки и светлячки разных цветов, вылетают тем гуще, чем быстрее движется мышь (линия за мышкой не рисуется, чтобы не мешать рисовать). На телефонах и при включённом в системе «уменьшении движения» отключена. 3D-параллакс персонажа за курсором.
- Адаптивная вёрстка для телефона, рисование пальцем.
- Форма связи отправляет письмо на почту художницы (настраивается в `.env`). Если почта не настроена, форма открывает почтовую программу или Telegram с готовым сообщением.
- Блоки «Обо мне» и «Что я рисую» (услуги, этапы работы, текст правится в `site_data.py`: SERVICES, STEPS, и в шаблоне). Нижний блок сайта (подвал): навигация, контакты и подпись «Сайт сделан студией Bellunium».

## Стек
Python, FastAPI, Jinja2, WebSocket, SQLite, чистые HTML/CSS/JavaScript.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows (на Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000

## Структура
```
main.py              сервер: страницы, API, WebSocket
drawing.py           проверка мазков и ограничение частоты (не зависит от FastAPI)
site_data.py         работы, книги, герои игры, подбор картинок
characters.example.json  пример списка героев (скопируйте в characters.json)
templates/index.html страница (вёрстка, стили и JS в одном файле)
static/images/       картинки (в репозиторий не входят, см. ниже)
```

## Картинки
Папка `static/images/` с иллюстрациями в репозиторий не загружается (это авторские работы).
Чтобы сайт показал всё полностью, положите туда файлы с такими именами:
`photo.jpg`, `character1.png`, `paper.jpg`, `portfolio1.JPG` ... `portfolio4.JPG`,
`tsmok_1.jpg` ... `tsmok_6.jpg`, `lisenok_1.jpg` ... `lisenok_4.jpg`, `novigod_1.jpg` ... `novigod_4.jpg`.
При запуске сервер пишет в консоль, каких картинок не хватает.

## Герои игры
Пока героев нет, показываются заглушки со смайликами. Чтобы поставить своих:
1. Положите PNG (или WebP) с прозрачным фоном в `static/images/characters/`. Лучше 400–800 px по большей стороне.
2. Название файла станет именем героя в «Книге героев»: назовите файл `Цмок.png` или `Лисёнок.png`.
3. Перезапускать сервер не нужно, достаточно обновить страницу. Места раскладываются автоматически.

Хотите указать книгу, подсказку и точное место? Скопируйте `characters.example.json` в `characters.json` и впишите героев:
`section` (intro, portfolio, gallery, contacts), `left` и `top` (проценты от раздела), `size` (px), `rot` (поворот), `book`, `hint`.
Герои из папки, которых нет в `characters.json`, добавятся сами.
Список книг и работ редактируется в `main.py` (функция `home`).

## Деплой
Нужен хостинг с Python и поддержкой WebSocket (VPS, Render, Railway, Fly.io и подобные).
Обычный shared-хостинг для статических сайтов не подойдёт.


## Почта для формы связи

1. Скопируйте `.env.example` в `.env` (файл не попадает в git).
2. Заполните: `CONTACT_EMAIL` (куда приходят письма, по умолчанию angry.miu@gmail.com), `SMTP_HOST`, `SMTP_PORT`,
   `SMTP_SECURITY` (`starttls`, `ssl` или `none`), `SMTP_USER`, `SMTP_PASSWORD`, при необходимости `CONTACT_FROM`.
3. Для Gmail: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, `SMTP_SECURITY=starttls`,
   в `SMTP_PASSWORD` нужен «пароль приложения» (включите двухфакторную защиту в аккаунте Google).
4. Перезапустите `uvicorn main:app`.

Защита от спама: скрытое поле-ловушка и лимит (3 письма за 10 минут с одного IP).
